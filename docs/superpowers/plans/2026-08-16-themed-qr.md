# Themed Wedding QR Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the plain wedding QR assets with ivory, forest-green, and gold themed versions that remain reliable for phone scanning.

**Architecture:** Regenerate the existing PNG and SVG assets from the same URL using the QR CLI’s color options, then verify the files locally and through GitHub Pages. The QR symbol remains untouched apart from its foreground/background colors and surrounding presentation.

**Tech Stack:** `npx qrcode`, PNG, SVG, GitHub Pages, curl.

## Global Constraints

- The encoded URL must remain exactly `https://riddhishpandya.github.io/arshiandamar/`.
- Keep QR modules unobstructed; do not place a logo or text over the encoded area.
- Preserve a generous quiet zone for reliable phone scanning.
- Publish both `assets/arshiandamar-qr.png` and `assets/arshiandamar-qr.svg`.

---

### Task 1: Regenerate and publish themed QR assets

**Files:**
- Modify: `assets/arshiandamar-qr.png`
- Modify: `assets/arshiandamar-qr.svg`

**Interfaces:**
- Consumes: the live URL and existing asset filenames.
- Produces: a 1600px PNG and scalable SVG using ivory `#f7f3ed`, forest green `#17362c`, high error correction, and a four-module quiet zone.

- [ ] **Step 1: Generate themed PNG and SVG assets**

```bash
npx --yes qrcode -e H -w 1600 -q 4 -d 17362c -l f7f3ed \
  -o assets/arshiandamar-qr.png \
  'https://riddhishpandya.github.io/arshiandamar/'
npx --yes qrcode -e H -t svg -q 4 -d 17362c -l f7f3ed \
  -o assets/arshiandamar-qr.svg \
  'https://riddhishpandya.github.io/arshiandamar/'
```

- [ ] **Step 2: Inspect dimensions and colors**

```bash
file assets/arshiandamar-qr.png assets/arshiandamar-qr.svg
rg -q '#17362c' assets/arshiandamar-qr.svg
rg -q '#f7f3ed' assets/arshiandamar-qr.svg
```

Expected: PNG is 1600×1600, SVG is present, and both theme colors are present in the SVG.

- [ ] **Step 3: Commit and push the themed assets**

```bash
git add assets/arshiandamar-qr.png assets/arshiandamar-qr.svg
git commit -m "Style wedding QR code for phone sharing"
git push
```

- [ ] **Step 4: Verify GitHub Pages deployment**

```bash
gh api repos/riddhishpandya/arshiandamar/pages/builds/latest --jq '{status,updated_at}'
curl -L -sS -o /dev/null -w 'PNG HTTP %{http_code}\n' \
  https://riddhishpandya.github.io/arshiandamar/assets/arshiandamar-qr.png
curl -L -sS -o /dev/null -w 'SVG HTTP %{http_code}\n' \
  https://riddhishpandya.github.io/arshiandamar/assets/arshiandamar-qr.svg
```

Expected: Pages status is `built` and both assets return HTTP 200.
