# Arshi & Amar Wedding Seating

Simple, mobile-first wedding seating lookup page.

## Add the seating chart

Place the supplied seating chart image at:

`assets/seating-chart.png`

The page will show a friendly fallback message until that file is present.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server. The site has no build step and can be deployed directly to GitHub Pages, Netlify, or Vercel.
